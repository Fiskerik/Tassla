Delegerade skärmars egna renderers läses i respektive fil. Native Alert återger även Avbryt utan callback (inklusive as const). System-API:er för behörighet, delning och externa länkar registreras som Systemyta; deras egna knappar styrs av plattformen. Dynamiska planned-health action-buildern läses som objekt även utanför Alert-anropet. Ingen data från användarkonton används.
