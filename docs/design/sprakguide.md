# Tasslas språkguide

Tala varmt och enkelt till hundägaren, som en lugn och kunnig följeslagare. Ge ett konkret nästa steg utan skuld, prestationskrav eller antaganden om hundens utveckling. Var tydlig med vad som är känt och vad som behöver kontrolleras, särskilt när något kanske inte har sparats.

## När något går fel

Beskriv läget kort och ge ett konkret nästa steg när det finns. Skilj mellan väntande, bekräftat sparat, misslyckat och okänt läge; visa framgång först när sparningen är bekräftad. Erbjud omförsök bara när flödet faktiskt kan göra det säkert. Dölj inte information som krävs för att undvika dubbelregistrering eller förstå att en ändring kan saknas; mer tekniska detaljer kan läggas bakom en frivillig fördjupning när ett sådant gränssnitt finns.

Exempel på osäker sparning: ”Vi kunde inte se om ändringen sparades. Kontrollera den igen.” Anpassa alltid återförsöksråd till det faktiska flödet: uppmana inte till att skapa en ny registrering om den första kan ha sparats.

## Innehåll och personliga uppgifter

Påstå inte att råd är individuella eller mänskligt granskade utan faktisk grund. Använd hundens namn bara där användaren rimligen väntar sig det; notiser kan synas på låsskärmen och behöver ett uttryckligt produktval innan de görs mer personliga.
