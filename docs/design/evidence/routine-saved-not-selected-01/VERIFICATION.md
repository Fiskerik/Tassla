# ROUTINE-SAVED-NOT-SELECTED-01

Gemensam notiskomponent renderad på syntetiskt Hem vid 375/430 och 375×667 med CSS 140 %. Aktuell hund får öppna rutinhanteraren och notisen bevaras; annan hund hänvisas till den klickbara hundbilden, saknad hund får inget trasigt val. UIcritic granskade bilderna och fann inga kvarstående blockerare inom scope. Varianten med öppnaknapp vid CSS 140 % är inte separat renderad; native Dynamic Type, VoiceOver och verkliga data är inte testade. Panel1 är inte därmed fullständigt visuellt godkänd.
