Renderad headless RN Web-QA finns nu i [visuell checklista](../design/UI-08/checklist.md), inklusive 360/430, 140 %-webbstresstest och skaljämförelser mot rev02. Matrisens minima 62.39 px bredd och 58 px höjd är separata webbreferenser och kan komma från olika rader. RN Web verifierar inte heller native Dynamic Type, rörelse, skärmläsare eller safe-area.
