# CI-02 v1 – synka Reanimated med Expo SDK 57

Mandat: fortsättning på Codemagic-bygget efter Eriks nya iOS-logg 2026-10-05. Nuvarande låsfil drar in `react-native-reanimated@4.7.1` och `react-native-worklets@0.10.1`; CocoaPods stoppar med krav på Worklets 0.13+. Projektets installerade Expo 57 `bundledNativeModules.json` anger Reanimated 4.5.1 och Worklets 0.10.1. SDK 57 changelog säger att SDK:s avsedda versioner är Reanimated 4.3–4.5 och Worklets 0.8–0.10. Reanimated-tabellen bekräftar att 4.5.x stöder Worklets 0.10.x och React Native 0.86.

Källor: lokalt `node_modules/expo/bundledNativeModules.json`; [Expo SDK 57 changelog](https://expo.dev/changelog/sdk-57); [Reanimated compatibility](https://docs.swmansion.com/react-native-reanimated/docs/guides/compatibility/).

## Avgränsad plan
Pinna den transienta `react-native-reanimated`-versionen till Expo SDK:s rekommenderade `4.5.1` i `pnpm-workspace.yaml` overrides. Behåll worklets `0.10.1` enligt Expo. Regenerera `pnpm-lock.yaml` med pnpm 11.19.0. Ändra inte Expo/RN-versioner, annan dependency, appfunktion, certifikat eller publiceringsinställningar.

Acceptans: installerad Expo bundled module version och låsfil överensstämmer; ingen Reanimated 4.7.x/Worklets 0.10-kombination; `pnpm install --frozen-lockfile`, `pnpm check`, iOS JS-export och statisk versionskontroll passerar. macOS/CocoaPods finns inte lokalt; Erik verifierar native-bygget i Codemagic efter push. Ingen Codemagic-cloudbyggning eller betalda API-anrop av agenten.

Skrivägande: `pnpm-workspace.yaml`, `pnpm-lock.yaml`; checkpoint `docs/tasks/dev/ci-02.md`; kö `docs/tasks/dev/queue.json`.

Tech Lead (`architecture_astra`): APPROVE för CI-02 v1. Expo bundle visar exakta versioner; native-kompatibilitet verifieras utan manifest dependency additions.

Critic (`critic`): PROCEED. Planen håller sig till kompatibilitetsfixen; verklig CocoaPods/Codemagic-validering återstår hos Erik.
