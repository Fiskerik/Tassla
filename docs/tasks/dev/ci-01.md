## Avgränsad deluppgift
Implementer ändrar endast `codemagic.yaml`: ersätt global installation och efterföljande install med `npx --yes pnpm@11.19.0 install --frozen-lockfile`; kör också check med `npx --yes pnpm@11.19.0 check`. Versionen motsvarar package.json. Ingen force, radering av globala verktyg, paketuppgradering eller ändring av signering/publicering.

Acceptans: båda stegen använder exakt version, lockfilen är fryst, ingen global pnpm-fil skrivs över. QA kör projektets check och granskar kommandona mot npm:s officiella npx-dokumentation. Oberoende reviewer granskar diffen. Molnkörning på Mac verifieras separat av Erik; lokala kontroller bevisar inte signering eller TestFlight.

Källa: https://docs.npmjs.com/cli/v11/commands/npx/ beskriver versionsval och att cachelagrade paketbinärer läggs i barnprocessens PATH.

Tech Lead (`architecture_astra`): APPROVE för CI-01 v1. Versionslåsta npx-anrop undviker den globala konflikten och behåller fryst lockfil. Lokal kontroll och molnbygge redovisas separat.
