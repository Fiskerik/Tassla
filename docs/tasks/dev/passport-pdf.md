Plan v1 2026-10-06. Full MVP mandate Luna medium; Erik approved PDF fields/preview/owner sharing and necessary Expo packages. Exact review before code; P01–P03 checkpoint first. No remote/public sharing service.
## DATA checkpoint
Build a typed immutable passport snapshot for current dog from confirmed profile, newest weight (label latest recorded weight/date), performed vaccination/vet history. Planned events excluded. Owner chooses include-profile/include-weight/include-health; preview is EXACT export snapshot. Dates/data shown as owner recorded, created timestamp/local date and not official passport/certificate/vaccination card. Cap/incomplete history disclosed and no report claims complete journal. Treat content as text; strict HTML escape all names/breed/notes including quotes/ampersand/<>, no remote images/fonts or dynamic scripts. Empty fields/history show honest absence. Unknown pending writes require confirm reading current saved data or block snapshot until resolved, no unsaved notes exported.
## UI checkpoint
PassportScreen actual preview with readable branded headers, paw/document icons, selectable sections and one explicit Create PDF / Share action. Local available settings and status; disable duplicate export. Preview stable during async export; captured dog/session lifetime blocks any later share after switch. Back/unmount doesn't trigger external share. On user sharing failure offer retry from same snapshot if current context still matches.
## Native export checkpoint
Install Expo-compatible expo-print ~57.0.2, expo-sharing ~57.0.22 and expo-file-system ~57.0.7 per installed Expo metadata, no unrelated dependency. Verify installed API types + official SDK57 pages before using. printToFileAsync from sanitized snapshot HTML produces local PDF; Sharing.isAvailableAsync then shareAsync only by owner's action. Temp file stored only app cache and deleted on successful/cancelled/failed export once native share promise finished; best-effort cleanup on next startup for app-owned export prefix only, never wipe generic cache. Native share cancellation doesn't falsely show delivered. No upload/public URL/partner recipient.
