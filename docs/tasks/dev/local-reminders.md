# P07 — lokala påminnelser
Plan v1 2026-10-06, Erik full MVP mandate Luna medium; lokala notiser och behövliga Expo-paket godkända. Implementation efter föregående checkpoint och exact planreview. Ingen fjärrpush/APNs-token/Expo Push Service.
## DATA/kontrakt
Planerade händelser får opt-in reminder_enabled boolean default false och reminder_minutes (0..1439) för ägarvald lokal tid; exakt narrow migration med owner-grants/constraints och preimagefält. Befintliga planer default av. En separat lokal frivillig träningspåminnelse väljer HH:MM och är av som standard. Global device/account preference lagras i befintlig SecureStore-adapter, endast nödvändiga ID/bool/tid; ändamål faktisk ägarvald påminnelse, inga analytics/hälsoanteckningar/token.
Skapa native tid från kalenderdatum+valda timme/minut i enhetens tidszon; visa detta. Förfallna/passerade påminnelsetider skapar inte retroaktiv notis och markeras oschemalagda. Redigera/radera/disable avbokar tidigare logical plan-ID. Logiska identifierare stabila konto/hund/plan-ID; aktuelldog/account koppling kontrolleras. Begränsa egen schemaläggning till 40 tidigaste framtida planer +1 träningspåminnelse; fler är explicit inte schemalagda och visas som sådana, inte påstådda levererade.
## NATIVE/lifecycle checkpoint
Installerad Expo metadata anger expo-notifications ~57.0.21 (patch inom samma range kan välja senare; inga SDK-uppgraderingar). Kontrollera installed definitions och SDK57 docs före användning. get/requestPermissionsAsync endast efter användarhandling, denied ger fungerande app utan notiser. Native schedule/cancel/getAll APIs via liten specifik adapter och ingen extern service. Set foreground handler och fixed channel där SDK kräver.
Serialisera reconcile/schedule med generation/account guard; kontroller efter varje await innan nytt native side effect. Appstart/foreground läser aktuella ägarplaner/preferens och jämför schedule, annars osäkert/felstatus. Varje avbokning gäller endast appens egna identifiers/payloadprefix. Logout/kontobyte/hundradering avbokar kontots notiser, local preference default av för annan ägare. Misslyckad cleanup får inte hindra lokal utloggning eller påstå att alla avbokats. Generisk notistext utan hundnamn/anteckning/klinisk uppgift skyddar låsskärmen; klickdata är bara whitelisted page+IDs.
Response listener öppnar bara health/training för aktuell inloggad ägare och ägd hund, aldrig arbitrary URL. Återstart via notis hanteras utan osäkert korskontonavigering; foreign/stale payload ignoreras. Ingen notisflagga innebär faktisk leverans: UI skiljer vald, schemalagd, nekad/fel/passerad/över gräns. Native leverans testas enligt Eriks val av kritiska telefonprov.
