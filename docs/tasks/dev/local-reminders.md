## DATA/kontrakt
Planerade händelser får opt-in reminder_enabled boolean default false och reminder_minutes (0..1439) för ägarvald lokal tid; exakt narrow migration med owner-grants/constraints och preimagefält. Befintliga planer default av. En separat lokal frivillig träningspåminnelse väljer HH:MM och är av som standard. Global device/account preference lagras i befintlig SecureStore-adapter, endast nödvändiga ID/bool/tid; ändamål faktisk ägarvald påminnelse, inga analytics/hälsoanteckningar/token.
Skapa native tid från kalenderdatum+valda timme/minut i enhetens tidszon; visa detta. Förfallna/passerade påminnelsetider skapar inte retroaktiv notis och markeras oschemalagda. Redigera/radera/disable avbokar tidigare logical plan-ID. Logiska identifierare stabila konto/hund/plan-ID; aktuelldog/account koppling kontrolleras. Begränsa egen schemaläggning till 40 tidigaste framtida planer +1 träningspåminnelse; fler är explicit inte schemalagda och visas som sådana, inte påstådda levererade.
