# Betrodda serveroperationer
Här byggs avgränsade funktioner vid konkret behov, först säker kontoradering. Inga funktioner är installerade eller deployade. Privilegierade nycklar får bara finnas i betrodd servermiljö.

Radering ska autentisera/bekräfta och kunna återupptas efter delvis fel. SQL-trigger för hundstädning ersätter inte raderings-API, backupplan eller användarinformation.
