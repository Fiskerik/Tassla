# Repository skill index

Canonical repository skills live in `.agents/skills/<name>/SKILL.md`. Use the short skill description to decide relevance, then read only the selected skill. Do not maintain duplicate copies under `.codex/skills/`.

- `tassla-consumer-ux`: interaction, feedback, state, and accessibility guidance for user-facing work.
- `mobile-ios-design`: iOS platform guidance for Expo/React Native screens.

Task scope, approved decisions, `AGENTS.md`, and `docs/design-rules.md` take precedence as described in those documents.
