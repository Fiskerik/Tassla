# Visuell grund
tokens.ts är en första färg-/avstånds-/typografiförslag utifrån vision_rev01.jpg. Systemets egna teckensnitt används initialt; inga fontdownloads eller animationbibliotek är valda.

Slutliga komponenter ska testas med stor text, skärmläsare, kontrast och reducerad rörelse. Taktile trycktillstånd och skärmövergångar implementeras i UI-uppgiften; tokens är inte färdiga komponenter.
