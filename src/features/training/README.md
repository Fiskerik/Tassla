# Träning

`PublishedTrainingScreen.tsx` visar publicerade program, programmets hela text och källor före stegen, kontoägd registrering och bekräftad återställning. `ProductWorkspace.tsx` läser via `src/data/workspace-data.ts`: endast publicerade versioner/steg och aktuell hunds `training_progress`. En startad och fortfarande publicerad version återupptas framför en nyare version; indragna eller saknade versioner redovisas som pausad historik.

Nästa-övning-kortet använder den dekorativa fyrkantiga corgibilden `training-next-step-puppy-corgi-home.jpg` i befintlig `tokens.size.trainingImage`-storlek. HomeCarousel använder samma motiv för nästa träningssteg. Bilden påverkar inte val av program/steg, progress eller knappens handling och ignoreras av skärmläsare. Källa, generering och beskärning finns i `assets/images/README.md`.

Ett steg sparas med riktiga versions- och steg-UUID genom insert/select. Nästa steg väntar på ett separat knapptryck efter bekräftelse. Ett markerat steg kan avmarkeras separat: `ProductWorkspace` tar bort exakt aktuell hund, programversion och steg med `deleteTrainingProgress`, läser om programmet och uppdaterar Home först när steget saknas i den återlästa progressen. Failed/unknown behåller den senast bekräftade bocken och visar status med retry. Senare steg påverkas inte. Återställning av hela programmet är fortsatt en egen bekräftad åtgärd; ingen upsert/update-grant eller automatisk svårighetsökning används. Registrering beskriver ägarens markering, inte hundens färdighet.

`TrainingScreen.tsx` och `training-model.ts` är bara för lokal preview och dess internt granskade syntetiska text. Normalflödet har inget program som reserv när publicerat innehåll saknas. Kör `pnpm check`; verklig RLS-åtkomst och publicerat datainnehåll behöver separat miljötest.

TRÄNING-REDESIGN (ersätter UI-RESET-beskrivningen nedan av flikar och bildkort): `PublishedTrainingScreen` har inga flikar. Översikten visar en enda primär handling, **Nästa övning** (fortsätt ett påbörjat program först, annars börja första ej påbörjade), och **Era program** som kort med status och framsteg, sorterade stabilt: pågående, ej påbörjade, program utan övningar, klara. Alla statusar, antal, procent och synlighet för **Börja om** räknar enbart slutförda ID:n som finns bland stegen i den aktuella programversionen; gamla och dubblerade ID:n ignoreras. Ett program öppnas i samma skärm med Tillbaka och visar övningarna i ordning: nästa övning som eget kort med **Öva nu**, klara som bockade rader och kommande som rader med "Kommer efter övning N". Statusen finns i synlig text och tillgängliga etiketter. Alla övningar går fortfarande att läsa i panelen, men bara den första ej genomförda kan markeras. Tom programlista, program utan övningar och alla övningar klara är separata lägen. "Alla övningar är genomförda" visas bara om minst ett program finns och varje listat program innehåller övningar som alla är klara. Regler för status, ordning och nästa övning ligger i `training-overview.ts`; riktade tester finns i `tests/training-overview.test.mjs` och körs med `node --experimental-strip-types --test tests/training-overview.test.mjs`. Skärmen visar bara program som redan är hämtade; ålderslåsta program visas därför inte. **Börja om** finns bara inne i ett program. Ordet övning används för steg i hela gränssnittet.

UI-RESET (historik): `PublishedTrainingScreen` följde rev02:s varma canvas, vänsterställda titel och kapselsegmenten `Rekommenderat`, `Alla övningar` och `Mina`. Rekommenderat visar hundens redan beräknade ålder, tvåkolumniga bildkort och ett kompakt liggande fortsättkort endast när det finns markerade steg och ett nästa tillåtet steg. Fortsättkortet är en egen grupperad sektion; det visas även när åldern är okänd, separat från åldersbaserade rekommendationer. Kortet öppnar samma programversion och steg som tidigare. `Alla övningar` grupperar de redan hämtade stegen. Public `Mina` visar endast program med bekräftade progressmarkeringar; review `Mina` visar bara lokala markeringar och reviewtexten förblir synlig. Alla övningar kan läsas i sheet; endast nästa steg kan markeras, och först efter bekräftat sparande uppdateras produktprogress. Ett bekräftat markerat steg kan avmarkeras från detaljbladet med en namngiven handling; review-exempel ändras bara lokalt. Återställning behåller sin separata bekräftelse. Programtext/källor nås via Om programmet. Inga nya träningsråd, favoritdata, rekommendationsmotor eller innehållspubliceringar ingår.

Bekräftad träningsåterkoppling visas utan valpfigur. Spara- och radstatusen är fortsatt knuten till den bekräftade serverposten.

Explicit review builds may use three versioned `review-v1:training:*` layout examples when the real published program query succeeds with an empty list. These rows use `PublishedTrainingScreen` with `reviewMode`; completion and reset live only in component memory and never call `training_progress` handlers. A real fetch error remains an error with retry and does not reveal examples. Copy is marked as an unreviewed temporary example in the view.

## Tomt och saknat åldersunderlag (5b)

När hundens ålder saknas visar Träning Lägg till födelsedatum och öppnar den befintliga Hundprofilredigeringen. Tillbaka och bekräftad sparning går till Träning. När en lyckad åldersfiltrering inte hittar publicerade program visas Öppna Kunskap; Kunskaps tillbakaåtgärd går tillbaka till Träning. Profilens åldersändring ingår i befintlig urvalsscope, så Training hämtar om innehållet för den nya åldern. Läsladdning och fel med Försök igen förblir separata; tillfälliga exempel visas endast efter lyckad tomläsning i uttryckligt granskningsläge, aldrig som svar på ett fel.
