# Hälsa

`HealthScreen.tsx` nås från Mer både i arbetsytan och lokal preview. Den visar en medveten tom grund med tydligt besked att inga hälsodata, vårdscheman, påminnelser eller medicinska råd finns ännu. Skärmen tar ingen hund- eller backenddata och gör inga auth-, nätverks- eller lagringsanrop.

Kör `pnpm start:preview` för lokal preview och `pnpm check` för typkontroll, lint och tester. Hälsoregistrering och medicinskt innehåll kräver en separat godkänd uppgift och relevant granskning.
